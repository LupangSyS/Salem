# เซเลม 1692 — เกมการ์ดล่าแม่มดออนไลน์

เกมการ์ดแนวหลอกล่อ (bluff) อิงกติกา Salem 1692 สำหรับผู้เล่น 4–12 คน เล่นผ่านเบราว์เซอร์
ทุกคนมีการ์ดไต่สวนคว่ำไว้ บางคนเป็น **แม่มด** ที่ซ่อนตัวอยู่ ชาวเมืองต้องกล่าวหาจนเปิดโปงแม่มดให้หมด
ส่วนแม่มดต้องกำจัดชาวเมืองในยามราตรีจนเหลือแต่พวกตัวเอง
บอทเติมที่นั่งว่างได้ และบอท **คุยในแชท** — กล่าวหา แก้ตัว และแม่มดบอทก็โกหกเหมือนคนจริง

> หน้าเว็บภาษาไทย รองรับมือถือจอ 400px และเดสก์ท็อป · โต๊ะวงรี ที่นั่งของคุณอยู่ล่างสุด (กรอบทอง ป้าย "คุณ") · ลูกศรจากผู้เล่นการ์ดไปยังเป้าหมาย

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm start          # เปิดเซิร์ฟเวอร์ที่ http://localhost:3000
npm test           # จำลองเกมบอทล้วน 306 เกม (4–12 คน) + ทดสอบกฎ + ทดสอบห้องผ่าน socket + ตรวจภาพ
npm run test:ui    # เปิดหน้าเว็บจริงใน Chromium (เดสก์ท็อป 1280×800 + มือถือ 400px) เล่นจนจบ ตรวจ error และเลย์เอาต์
npm run build:art  # วาดภาพทั้งหมดใหม่จากโค้ด (ผู้ดูแลเท่านั้น)
```

`test:ui` ใช้ Playwright — ถ้ายังไม่มีเบราว์เซอร์ให้รัน `npx playwright install chromium` ครั้งแรก
ภาพหน้าจอจากการทดสอบถูกบันทึกที่ `test-results/`

ตัวแปรสภาพแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `BOT_DELAY` (ms ที่บอทใช้คิด ค่าเริ่มต้น 2500)

## ขึ้นเว็บฟรีด้วย Render

1. สมัคร/เข้าสู่ระบบ https://render.com ด้วยบัญชี GitHub
2. กด **New → Web Service** แล้วเลือก repo `Salem`
3. ตั้งค่า:
   - **Branch**: `main`
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. กด **Create Web Service** รอสักครู่ จะได้ลิงก์แบบ `https://salem-xxxx.onrender.com` ส่งให้เพื่อนได้เลย

ข้อควรรู้ของแผนฟรี: ถ้าไม่มีคนใช้ ~15 นาที เซิร์ฟเวอร์จะหลับ (เปิดครั้งแรกรอ ~1 นาที)
และ **ทุกครั้งที่เซิร์ฟเวอร์หลับหรือรีสตาร์ท ห้องที่เล่นอยู่จะหายไปทั้งหมด** เพราะสถานะเกมเก็บไว้ในหน่วยความจำเท่านั้น (ยังไม่มีฐานข้อมูล)
Render จะ deploy ใหม่อัตโนมัติทุกครั้งที่มีการ merge เข้า `main`

## กติกาโดยย่อ

- **การ์ดไต่สวน** (บทบาทลับ): ไม่ใช่แม่มด / แม่มด / ผู้คุ้มกัน — ใครเคยถือการ์ดแม่มดคือแม่มดตลอดเกม แม่มดรู้จักกันเอง

  | ผู้เล่น | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 11 | 12 |
  |---|---|---|---|---|---|---|---|---|---|
  | การ์ดไต่สวนต่อคน | 5 | 5 | 5 | 5 | 4 | 4 | 3 | 3 | 3 |
  | การ์ดแม่มด | 1 | 1 | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
  | ผู้คุ้มกัน | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |

- **รุ่งอรุณ**: แม่มดเลือกผู้ถือแมวดำ (ให้ตัวเองก็ได้) — **ผู้ถือแมวดำเริ่มเล่นก่อน** แล้ววนตามเข็มนาฬิกา
- **ในตาของคุณ**: จั่ว 2 ใบ **หรือ** เล่นการ์ดกี่ใบก็ได้ (ถือการ์ดได้ไม่จำกัด) · **ห้ามเล่นการ์ดใส่ตัวเองเด็ดขาด**
- **กล่าวหา**: การ์ดแดงรวมครบ 7 แต้ม → ผู้ที่เล่นใบสุดท้ายเลือกการ์ดไต่สวนที่คว่ำของเป้าหมาย 1 ใบให้เปิด เปิดเจอแม่มด = ตาย, เปิดหมด = ตาย แต้มที่เกินไม่ทบ
- **ราตรี** (การ์ดใบล่างสุดของกองเสมอ): แม่มดตกลงเลือกเหยื่อ (ไม่ตรงกันมีรอบสอง แล้วใช้เสียงข้างมาก) → ผู้คุ้มกันวางค้อนหน้าผู้เล่นอื่น 1 คน (ทุกคนเห็น) → ใครก็ได้เลือกสารภาพ → เหยื่อตาย เว้นแต่มีค้อน/สารภาพ/มีสถานพักพิง → สับกองทิ้งเป็นกองใหม่ ราตรีกลับไปล่างสุด · จั่วเจอราตรีเป็นใบแรก ได้จั่วใบที่สองหลังราตรี
- **ผู้คุ้มกัน**: ถ้าการ์ดผู้คุ้มกันถูกเปิด บทบาทนี้หายไปจากเกม · เสียการ์ดไปจากสมรู้ร่วมคิด = ไม่ใช่ผู้คุ้มกันแล้ว
- **สมรู้ร่วมคิด** (ตำแหน่งสุ่ม): ผู้จั่วเลือกการ์ดของผู้ถือแมวดำให้เปิด 1 ใบ (ถ้าไม่มีใครถือแมวดำ ข้าม) แล้วทุกคนหยิบการ์ดไต่สวน 1 ใบ (ไม่เห็นหน้า) จากคนทางซ้ายพร้อมกัน
- **แมวดำ** นับเป็นการ์ดสีน้ำเงิน: คำสาปทิ้งได้ แพะรับบาปย้ายได้ · **ขื่อคา** ค้างหน้าเป้าหมายจนถูกข้ามตา (2 ใบ = ข้าม 2 ตา) · **แม่สื่อ** ทำงานเฉพาะการถูกฆ่าตอนกลางคืน และถ้าอยู่คนเดียวกันทั้ง 2 ใบให้ทิ้ง · เหลือ 2 คน = ทิ้งการ์ดน้ำเงินทั้งหมด
- **ชนะ**: ชาวเมือง = การ์ดแม่มดถูกเปิดครบ · แม่มด = ผู้ที่ยังมีชีวิตเหลือแต่แม่มด
- การ์ดเล่น 60 ใบ (คู่มือไม่ได้ระบุจำนวนแต่ละชนิด — ยังเป็นค่าที่เราประมาณ): กล่าวหา 35, หลักฐาน 5, พยาน 1, ข้อแก้ตัว 3, ขื่อคา 3, แพะรับบาป 2, ปล้น 1, วางเพลิง 1, คำสาป 1, สถานพักพิง 2, ความศรัทธา 2, แม่สื่อ 2, ราตรี 1, สมรู้ร่วมคิด 1
- **ตัวละคร 15 คน** (บุคคลในประวัติศาสตร์ปี 1692) แต่ละคนมีพลังพิเศษที่ออกแบบเองสำหรับเกมนี้ (ดูในเกมหรือคลังภาพ)

## ระบบห้องและการกลับเข้าเกม

- สร้างห้องได้รหัส 4 ตัว + ลิงก์เชิญ `?room=CODE` · หัวห้องเพิ่ม/เตะบอท และกดเริ่มเกม · แชทในห้อง (แม่มดมีช่องแชทลับของตัวเอง)
- เบราว์เซอร์แต่ละเครื่องมี token เก็บใน localStorage — รีเฟรชหรือเน็ตหลุดแล้วกลับมาได้ที่นั่งเดิม พร้อมคำสั่งที่ค้างอยู่
- ถ้าผู้เล่นหลุดแล้วถึงตาตัดสินใจ ระบบรอ ~12 วินาที แล้วให้บอทตอบคำสั่งนั้นแทน
- กด "ออก" ระหว่างเกม = ให้บอทเล่นแทนที่นั่งนั้นถาวร
- **แถบ "เกิดอะไรขึ้น"** เหนือโต๊ะบอกทุกเหตุการณ์เป็นประโยค (ใคร ทำอะไร กับใคร) พร้อมการ์ดบินจากผู้เล่นไปหาเป้าหมาย เป้าหมายสั่น/กะพริบ และเกมหยุดรอให้ทุกคนเห็น (เล่นการ์ด 2.5 วิ, เปิดการ์ด/ตาย 3.5 วิ, ราตรี 2 วิ, รุ่งเช้า 3.5 วิ, สมรู้ร่วมคิด 3 วิ; บอทคิด 2–3 วิ)
- ทุกการตัดสินใจมีเวลาจำกัด (ตาของตัวเอง 60 วินาที, คำถามสั้น 20 วินาที) · บันทึกเกม · หน้าผลเกมพร้อมปุ่ม "เล่นอีกครั้ง"

## 🖼 ภาพประกอบ (สร้างจากโค้ด บันทึกถาวร)

ภาพทั้ง 36 ภาพ — การ์ดเล่น 14 แบบ, การ์ดไต่สวน 3 แบบ, ตัวละคร 15 คน, หลังการ์ด 2 แบบ, แมวดำ และโต๊ะ —
**วาดจากโค้ดทีละพิกเซล (RGBA)** แบบ pixel art ด้วยตัวสร้างภาพใน `public/artgen/` (ไม่ใช้ AI ไม่ใช้ภาพจากเกมจริง)
แล้วบันทึกถาวรเป็นไฟล์ PNG ใน `public/art/` พร้อม `manifest.json` ที่เก็บลายนิ้วมือ SHA-256 ของทุกไฟล์

- ดูภาพพร้อมข้อมูลการ์ดได้ที่ `/gallery.html` (ติ๊ก "วาดใหม่สดจากโค้ดเพื่อเทียบ" ให้เบราว์เซอร์วาดใหม่แล้วเทียบกับไฟล์ทีละพิกเซล)
- ไม่มีหน้าแก้ไข/อัปโหลด และเซิร์ฟเวอร์ไม่มี API สำหรับเขียนไฟล์
- `npm test` ตรวจว่าไฟล์ทุกไฟล์ตรงกับที่ตัวสร้างภาพวาดทุกพิกเซล — ถ้ามีใครแก้ไฟล์ภาพ การทดสอบจะไม่ผ่าน
- ผู้ดูแลที่ต้องการเปลี่ยนภาพ: แก้ `public/artgen/designs.js` แล้วรัน `npm run build:art` และ commit

## โครงสร้างโปรเจกต์

```
server/
  index.js          เซิร์ฟเวอร์ Express + Socket.IO (+ /api/cards แบบอ่านอย่างเดียว)
  rooms.js          ระบบห้อง รหัสห้อง บอท แชท การกลับเข้าเกม
  game/
    cards.js        ข้อมูลการ์ด การ์ดไต่สวน ตัวละคร และตารางจำนวนการ์ด
    engine.js       เครื่องยนต์เกม (เซิร์ฟเวอร์ตัดสินทั้งหมด ทุกการตัดสินใจเป็น prompt ที่ await)
    bot.js          บอทที่รู้กติกา (ประเมินความน่าสงสัย แม่มดรู้พวกพ้อง)
    talk.js         บทพูดของบอทในแชท (กล่าวหา แก้ตัว หลอกล่อ ตอบคน)
public/
  index.html, app.js, style.css   หน้าเกม (HTML/CSS/JS ล้วน ไม่ต้อง build)
  cardface.js       หน้าการ์ด ภาพ → ชื่อ → ประเภท → ผล (ใช้ร่วมกับคลังภาพ)
  gallery.html/.js  คลังภาพแบบอ่านอย่างเดียว
  artgen/           ตัววาด pixel art (raster.js + designs.js)
  art/              ภาพ PNG ที่บันทึกถาวร + manifest.json
scripts/            build-art.js (วาดภาพลงไฟล์), png.js (ตัวเข้ารหัส PNG)
test/               engine / server / art tests (node:test) + ui/ (Playwright)
```

## ข้อจำกัดตอนนี้

- สถานะทั้งหมดอยู่ในหน่วยความจำ: รีสตาร์ทเซิร์ฟเวอร์ = ห้องหายหมด
- บทพูดบอทเป็นประโยคสำเร็จรูป (ไม่ใช้ AI ไม่มีค่าใช้จ่าย)
